main.js 文件说明
================

1. 功能概述
-----------
main.js 是 RPG Maker MV 游戏引擎的入口文件，负责初始化游戏和启动核心功能。

2. 主要功能
-----------
- 创建游戏窗口和画布
- 初始化游戏系统
- 加载游戏资源
- 启动游戏主循环

3. 关键方法
-----------
- SceneManager.run(Scene_Boot) - 启动游戏引导场景
- Scene_Boot.loadSystemImages() - 加载系统必需的图片资源
- Scene_Boot.start() - 开始游戏主流程

4. 使用注意
-----------
- 不建议直接修改此文件，因为它是游戏引擎的核心文件
- 如需扩展功能，请使用插件系统
- 文件修改可能导致游戏无法正常运行

main.js文件操作指南
====================

1. 文件概述
-----------
main.js是游戏的主要入口文件，负责初始化游戏并启动引擎。

2. 核心功能
-----------
2.1 插件管理器初始化
- 代码: PluginManager.setup($plugins)
- 功能: 设置并初始化游戏所需的所有插件
- 说明: 这行代码会读取plugins.js中定义的插件列表并进行加载

2.2 游戏启动
- 代码: window.onload = function() { SceneManager.run(Scene_Boot); }
- 功能: 在网页加载完成后启动游戏
- 说明: 
  * window.onload: 等待所有游戏资源加载完成
  * SceneManager.run(): 启动场景管理器
  * Scene_Boot: 引导场景，负责游戏初始化

3. 使用注意事项
--------------
- 此文件通常不需要修改，因为它是游戏引擎的核心启动文件
- 如需添加自定义功能，建议使用插件系统而不是直接修改此文件
- 确保不要删除或改变文件中的基本启动流程

4. 相关文件
----------
- plugins.js: 存储插件配置
- rpg_core.js: 核心引擎文件
- rpg_scenes.js: 场景管理相关文件

main.js 功能说明:

RPG Maker MV Core (rpg_core.js) 使用说明

1. 核心类和功能:

Utils - 工具类
- 提供判断平台类型、版本号等工具方法
- 支持 RGSS/MV 脚本兼容性

JsExtensions - JavaScript 扩展
- 为 Number/String/Array 等类型添加扩展方法
- 如 clamp()、contains() 等常用函数

Graphics - 图形系统
- 负责初始化和管理游戏画面
- 处理分辨率、缩放等显示相关设置
- 提供帧率控制和场景切换效果

Input - 输入处理
- 处理键盘、手柄的输入
- 支持按键映射和组合键
- 提供按键状态判定函数

TouchInput - 触摸输入
- 处理鼠标和触摸屏输入
- 支持多点触控
- 提供手势识别功能

2. 核心对象:

Bitmap - 图像处理
- 处理游戏中的所有图像资源
- 支持绘制、缩放、混合等操作
- 负责图像加载和缓存

Sprite - 精灵显示 
- 游戏中所有可视对象的基类
- 处理位图的显示和动画
- 支持变换和混合模式

WindowLayer - 窗口层
- 管理游戏中的所有窗口
- 处理窗口的层级和遮罩
- 支持窗口动画效果

WebAudio/Html5Audio - 音频处理
- 处理BGM、ME、SE等游戏音频
- 支持循环播放和淡入淡出
- 提供音量和音调控制

3. 主要功能:

资源管理
- 统一管理图像、音频等资源
- 支持资源预加载和释放
- 处理加载错误和重试

显示系统
- 处理游戏画面的渲染
- 支持分辨率自适应
- 提供场景切换效果

输入系统
- 统一处理各种输入方式
- 支持自定义按键映射
- 提供输入状态检测

4. 注意事项:

- 初始化顺序要正确,确保资源加载完成
- 注意内存管理,及时释放不需要的资源  
- 合理使用缓存,避免频繁创建对象
- 优化渲染性能,减少不必要的重绘
- 正确处理错误情况和异常

RPG Maker MV 核心系统说明文档

1. Utils 工具类
- 用于检测运行环境和处理基本功能的静态类
- 主要方法:
  - isNwjs(): 检查是否在 NW.js 环境中运行
  - isOptionValid(): 检查选项是否有效
  - isAndroidChrome(): 检查是否在Android Chrome中运行
  - isMobileDevice(): 检查是否在移动设备上运行
  - rgbToCssColor(): 将RGB值转换为CSS颜色字符串

2. Graphics 图形系统
- 负责处理游戏的图形渲染
- 主要功能:
  - 初始化图形系统
  - 设置画面分辨率
  - 设置拉伸模式
  - 管理渲染器(WebGL/Canvas)
  - 处理全屏显示
  - FPS显示控制

3. Input 输入系统
- 处理键盘和游戏手柄输入
- 关键属性:
  - keyMapper: 键盘按键映射
  - gamepadMapper: 手柄按键映射
- 主要方法:
  - update(): 更新输入状态
  - isPressed(): 检查按键是否按下
  - isTriggered(): 检查按键是否刚按下
  - isRepeated(): 检查按键是否重复

4. TouchInput 触摸输入系统  
- 处理鼠标和触摸屏输入
- 主要方法:
  - update(): 更新触摸状态
  - isPressed(): 是否按下
  - isTriggered(): 是否刚触发
  - isMoved(): 是否移动
  - x/y: 获取触摸坐标

5. 图像处理相关类
- Bitmap: 位图处理
- Sprite: 精灵对象
- Tilemap: 瓦片地图
- Window: 窗口对象
- WindowLayer: 窗口层

6. 音频处理
- WebAudio: Web Audio API 音频处理
- Html5Audio: HTML5 Audio 音频处理

7. 工具类
- JsonEx: JSON扩展,处理对象序列化
- Decrypter: 资源文件解密
- ResourceHandler: 资源加载管理

注意事项:
1. 图形渲染优先使用WebGL,降级使用Canvas
2. 音频优先使用Web Audio API,降级使用HTML5 Audio 
3. 移动设备需要特殊处理触摸事件和音频播放
4. 资源文件可能需要解密后才能使用

RPG Maker MV 核心系统(rpg_core.js)操作说明

1. Utils 工具类

- 包含格式化字符串、颜色转换等实用函数

- 初始化游戏画面和渲染器
- 控制游戏画面的缩放和全屏显示
- 处理游戏画面的更新和绘制

3. Input 输入系统 
- 处理键盘和手柄输入
- 支持按键映射和按键重复
- 处理方向键输入 

4. TouchInput 触摸输入
- 处理触摸屏和鼠标输入
- 支持长按、滑动等触摸操作
- 跟踪触摸坐标位置

5. Sprite 精灵类
- 用于显示图像的基本显示对象

7. Window 窗口类
- 用于显示游戏中的各种窗口
- 支持窗口外观的自定义
- 可以显示文字和处理输入

使用建议:
1. 了解这些系统的基本用法

3. 必要时可以通过插件扩展功能
